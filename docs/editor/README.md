# 3D 场景编辑器 · 总览

编辑器是一个 Vue 3 单页应用，四块布局：

```
┌────┬──────────────┬─────────────────────┬──────────────┐
│    │  左面板       │      视口            │  属性面板     │
│ 侧 │ ┌──────────┐ │                     │ ┌──────────┐ │
│ 栏 │ │ 搭建      │ │    Babylon 画布     │ │ 基础/变换 │ │
│ 导 │ │ 场景树    │ │                     │ │ 参数     │ │
│ 航 │ └──────────┘ │                     │ │ 交互     │ │
│    │              │                     │ │ 数据接入 │ │
│    │              │                     │ └──────────┘ │
└────┴──────────────┴─────────────────────┴──────────────┘
```

## 能力地图

| 分区 | 能力 | 详见 |
| --- | --- | --- |
| 搭建 | 七类可折叠栏目：场景底板 / 基础几何体 / 灯光 / 特效组件 / 模型自定义 / HTML 元素导入 / 环境天空盒 | [功能详解](features.md) |
| 场景树 | 节点层级、在线点（数据绑定状态）、眼睛（手动显隐） | [功能详解](features.md) |
| 视口 | 相机轨道、Gizmo 变换、选中描边、聚焦、交互实时预览 | [功能详解](features.md) |
| 属性 | 按类型自动生成的表单、折点编辑器、交互配置、数据绑定 | [节点交互](interactions.md) · [数据绑定手册](../binding-manual.md) |
| 顶栏 | 新建 / 保存状态 / 导出（需登录）/ 帮助 | [功能详解](features.md) |

## 三条设计主线

1. **拖参数拼场景**：不为建模，为「装配」——所有参数都是表单化的，改完即时预览
2. **文档是单一事实来源**：`editor.doc`（纯 JSON）是唯一真相，Babylon 只是它的投影；
   IndexedDB 自动保存，导出 = 序列化文档 + 补全资源引用
3. **WYSIWYG 到导出**：编辑器里看到的效果（交互、数据）与导出产物一致——
   交互运行时和播放包同源代码
