# 编辑器 · 功能详解

## 一、搭建栏（左侧七个可折叠栏目）

收/展状态记在 localStorage，刷新保持。

### 1. 场景底板

| 类型 | 说明 | 可调参数 |
| --- | --- | --- |
| 科技网格 | 深色发光网格，园区/通用 | 尺寸 / 网格间距 / 底色 / 线色 |
| 纯色平面 | 素色地面，工厂/占位 | 尺寸 / 颜色 |
| 机房防静电地板 | 600 格纹地板 | 尺寸 / 板宽 / 底色 / 线色 |
| 数字科技地板 | 圆形扩散波纹（自定义着色器） | 直径 / 流动速度 / 亮度 / 波纹颜色 |

> 格子实际大小不随「尺寸」变——贴图 `repeat = size / tile` 自动计算，尺寸放大几倍、
> 格子数同比放大。默认尺寸 2000，避免拉远镜头时地面“照不全”。

### 2. 基础几何体

立方体 / 球体 / 圆柱体 / 圆锥体 / 平面 / 圆环。点一下就放进场景，位置自动落在
当前相机目标点附近、底部贴地。

### 3. 灯光

半球环境光 / 平行光 / 点光源 / 聚光灯。方向型灯光每帧从节点朝向同步方向
（挂着节点转，光就转）。

### 4. 特效组件

| 特效 | 效果 |
| --- | --- |
| 能量管道 | 折点可配的流动管道：流动光带 + 管内粒子 + 半透明玻璃外壳 |
| 柔性管道 | 折点圆角倒角 + 流动纹理（babylon-datav 组件） |
| 流光线管道 | CatmullRom/圆角路径 + 光带（叠加混合） |
| 贝塞尔飞线 | 两端点 + 拱高，GreasedLine 渲染 |
| 围墙波纹 | 自定义顶点/片元着色器的波纹围墙 |
| 天气效果 | 雨 / 雪 / 晴 / 阴 / 雾 / 雷电（全局唯一，重复添加自动选中已有的） |

折点都在「参数 → 折点配置」里编辑：支持预设形状（直线/上扬/S 弯/阶梯/环形/螺旋）、
增删折点、逐轴改数值。

### 5. 模型自定义

上传 `.glb`（支持多选复用）→ 素材库存 blob → 点一下放一个实例。
场景节点只存 `assetId` 引用，同一素材可多实例不膨胀；删除素材会提示哪些节点受影响。

### 6. HTML 元素导入

手写一段 HTML，渲染成场景里的一块贴图面板（SVG foreignObject 栅格化）。
行内样式/文字/表格/简单 flex 都能照原样；`<script>`、外链字体、canvas、视频不生效
（栅格化时浏览器处于画图沙箱）。可选「始终朝你」（billboard）。

### 7. 环境天空盒

上传 `.hdr` → 天空盒 + 全局环境光照（IBL）。可调：环境光强度 / 水平旋转 /
天空盒模糊 / 天空盒开关。模糊度只影响天空盒，不动 IBL。

## 二、视口操作

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 旋转相机（ArcRotateCamera 轨道） |
| 右键拖动 | 平移（移动相机目标点） |
| 滚轮 | 缩放（半径上限 10000，远裁剪面 30000——大场景拉远不切断） |
| 点击物体 | 选中（黄色描边） |
| 点击空白 / 地面 | 取消选中 |
| `W` / `E` / `R` | 移动 / 旋转 / 缩放 Gizmo |
| `F` | 聚焦到选中物（包围盒中心 + 合适距离） |
| `Delete` | 删除选中节点 |

Gizmo 拖拽松手 → transform 自动回写文档（三位小数）。

## 三、场景树

- 节点按添加顺序排列；点击名字选中
- **在线点**：绿 = 该节点绑定的数据源在跑；灰 = 离线
- **眼睛**：悬停出现，手动显隐（手动是基线，数据注入的 `visible` 会临时覆盖）

## 四、属性面板

未选中 / 选中地面时显示**场景设置**（底板类型 / 底板参数 / 背景色 / 环境天空盒 /
**初始视角**）；选中节点时显示节点四段：

1. **基础**：名称 / 类型
2. **变换**：位置 / 旋转（度）/ 缩放，逐轴数值
3. **参数**：按类型自动生成（`sceneSchema` 的属性表驱动），含折点编辑器
4. **交互**：鼠标交互配置 → [节点交互](interactions.md)
5. **数据接入**：数据绑定配置 → [数据绑定手册](../binding-manual.md)

### 初始视角

未选中节点时「初始视角」分区：水平角 / 俯仰角 / 距离 / 目标点 XYZ，配
「用当前视角」「恢复默认」。存进 `scene.camera`，读档和导出都认。

## 五、保存与导出

- **保存**：文档任意改动 800ms 后自动写 IndexedDB（含 glb/hdr blob 素材库）；
  切后台/关页面前尽力落盘
- **导出**：右上角「导出」→ 单文件 HTML / 完整包 ZIP / 场景 JSON；
  模型按引用补全（内嵌 base64 或单独文件），素材丢了只占位不阻断
- **新建**：清空当前内容（会覆盖自动保存的那份）
